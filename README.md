# Half-Life-Week-3
Miniature synthesizer project
For this project, I have decided to make a miniature synthesizer powered by a Raspberry Pi Zero.
It will have 13 keys (1 octave) and a dial that will allow to change between 4 octaves.
The code will be done in arduino and the design in Kicad.
I am not a musician and therefore will use a friend to test its functionality in the build week.
